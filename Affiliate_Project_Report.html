4. Customer Discount Through Affiliate Links

Every valid affiliate link provides a 10% customer discount by default. The value is configurable through AFFILIATE_DISCOUNT_PERCENT.

  1. A visitor opens an affiliate URL.
  2. The platform stores a click event and creates a unique click_id.
  3. The store landing URL receives ref, click_id and affiliate_discount=10.
  4. The storefront validates the code and applies the discount at checkout.
  5. After successful payment, the final paid amount is recorded as a conversion.

Discount validation API: GET /referrals/discount/:code

Storefront integration required: The Alora ecommerce storefront must preserve ref and click_id through cart/checkout, validate the referral, and apply the discount. The storefront source code is not part of this workspace.

6. Conversion and Commission Workflow

  1. Affiliate shares a generated referral link.
  2. Customer clicks it; a click event is stored.
  3. Customer purchases from the store with the validated 10% discount.
  4. Store payment webhook calls POST /referrals/conversion.
  5. The platform creates a conversion and a pending commission.
  6. Duplicate order IDs are rejected from creating duplicate commissions.
  7. Admin can update commission status to pending, approved, rejected or paid.

Conversion payload:

{ referralCode, clickId, orderId, amount, currency }
